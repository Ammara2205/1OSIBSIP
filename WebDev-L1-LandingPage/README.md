# Lumora - Creative Landing Page

## Project Overview

Lumora is a fictional creative brand landing page developed as part of
the Oasis Infobyte Web Development and Designing Internship.

The project focuses on building a visually appealing, responsive,
and user-friendly static website using HTML5 and CSS3.

## Task Details

- Internship: Oasis Infobyte
- Track: Web Development and Designing
- Level: Level 1
- Task: Task 1 - Landing Page

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- CSS Media Queries

No JavaScript is required for this project.

## Features

- Sticky navigation bar
- Hero section with headline and call-to-action buttons
- Features section with three feature cards
- About section
- Contact section
- Footer with placeholder social and contact links
- Consistent colour palette
- Responsive desktop, tablet, and mobile layouts
- Hover effects and smooth scrolling
- Accessible navigation labels and keyboard focus styles
